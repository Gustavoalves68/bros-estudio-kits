# Kits do Bros Estúdio

Kits para baixar pelo Bros Estúdio (aba **Kits → Kits para baixar**). O próprio programa baixa, instala e prepara o kit.

| Arquivo | Kit |
|---|---|
| `growkaz-stickman-studio.zip` | GrowKaz Stickman Studio: vídeos narrados com bonecos stickman |

Para atualizar um kit, troque o arquivo mantendo o mesmo nome.
